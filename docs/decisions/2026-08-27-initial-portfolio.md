# Initial portfolio decision

## Context

Three families were discussed for the WebMCP hackathon: Quantech Vid, WebCCP, and a quantum connector spanning Qiskit, TorchQuantum, TensorFlow Quantum and Azure Quantum.

## Decision

- Preserve Quantech Vid in the dossier but reject it for this hackathon.
- Place WebCCP on the bench until context weight and decision value are understood.
- Evaluate all ten quantum concepts.
- Treat concepts 1, 3 and 9 as a provisional leading combination.

## Why this is reversible

No implementation has been selected and no upstream proposal has been made. A concept can replace the current favorite if its probe demonstrates greater WebMCP necessity, avoided-call value or scientific reliability.
