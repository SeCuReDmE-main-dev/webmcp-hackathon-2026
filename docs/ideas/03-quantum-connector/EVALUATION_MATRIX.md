# Concept evaluation matrix

Score each criterion from 0 to 5. No concept is selected until evidence is attached.

| Criterion | Weight | Meaning |
|---|---:|---|
| WebMCP necessity | 20 | Structured page tools materially improve the workflow. |
| Avoided-call value | 20 | The concept can prevent a measurable unnecessary action. |
| Scientific integrity | 15 | Deterministic libraries retain authority over calculations. |
| Originality | 15 | The contribution is not a generic circuit editor or chatbot. |
| Hackathon feasibility | 15 | One golden path can be built and demonstrated reliably. |
| Reproducibility | 10 | Decisions and results can be independently inspected. |
| Four-surface extensibility | 5 | The contract can accept adapters without false equivalence. |

## Required evidence per concept

- one exact user problem;
- one WebMCP tool contract;
- one deterministic fixture;
- one falsification condition;
- one security or cost risk;
- one demo boundary;
- one reason the concept should not be selected.
