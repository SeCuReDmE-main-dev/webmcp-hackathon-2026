# QCG final identity runtime map

Status: canonical distribution map  
Source packs:

- `asset/logo/`
- `asset/mascotte-inspecteur Q/`

The source packs remain unchanged reference artwork. Runtime assets are
deterministic derivatives generated by `scripts/generate-brand-assets.ps1`.
Their source and output hashes are recorded in
`evidence/releases/qcg-brand-runtime-manifest.json`.

## Product mark

The open-gate symbol in `asset/logo/logo A — épuré.png` is the compact runtime
mark. A fixed, text-free square crop is resized with high-quality interpolation
so the gate, locks and evidence path remain legible at browser-toolbar size.
The more detailed `icône app.png` remains artwork for large-format use; it is
not reduced into the Web header.

`asset/logo/thumbnail GitHub.png` supplies the social metadata card. It is
copied byte-for-byte to `public/brand/qcg-social-card.png` because its visible
claims match the bounded product: verifiable evidence, an open build and a
human-in-the-loop preflight gate.

## Inspector Q

Inspector Q is a decorative witness to bounded state. It is not an agent
identity, a verifier, a consent holder or a decision maker. A text-free square
crop from `mascotte — Inspector Q.png` becomes
`public/brand/inspector-q-avatar.jpg` and the byte-identical Companion avatar.
Both instances are hidden from assistive technology; the adjacent interface
text carries the meaning.

The original emotional scenes remain available for editorial and video work.
They do not determine runtime state.

## Excluded visual claims

The following concept boards are not distributed in the product because their
raster text contains invented metrics, capabilities or actors:

- `Q — Access Settings.png`
- `Q — Artifact State.png`
- `Q — Gemini Relay.png`
- `Q — Publish Review.png`
- `Q — Tool Tracker.png`

`Q — Human Decision.png` is also excluded from runtime because its composition
can make Inspector Q appear to press the human decision. `Q — Export
Receipt.png` remains editorial until its fixed timestamp and verification
language are removed.

Logo badge sheets containing `Execute` remain brand-development references.
They never create an Execute button, provider authorization or QPU capability.
