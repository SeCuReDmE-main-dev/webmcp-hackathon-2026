# Idea portfolio

## 1. Quantech Vid

Status: `REJECTED_FOR_THIS_HACKATHON`

Quantech Vid is a local-first FastAPI video-production studio with capture, narration, subtitles and reproducible rendering. It remains useful software, but WebMCP would mostly act as an alternate control surface. The core value still exists without WebMCP, so it is a weak match for a hackathon intended to demonstrate a browser-native agent tool surface.

It remains in this dossier because it was genuinely evaluated. Rejection is a decision artifact, not deletion.

## 2. WebCCP

Status: `DEFERRED_BENCH`

The earlier study established that CCP belongs above WebMCP as an external harness contract rather than inside the specification. The current blocker is deeper: until the cost and decision value of each field are understood, adding another context envelope risks increasing data weight instead of improving continuity.

WebCCP may return when it can answer all three questions:

1. Which bytes change the next decision?
2. Which bytes can be fetched lazily instead of injected?
3. Is the total context cost lower than a matched summary or a fresh tool lookup?

## 3. WebMCP Quantum Connector

Status: `ACTIVE_RESEARCH`

This lane uses WebMCP as a structured preflight and evidence interface for four distinct surfaces: Qiskit, TorchQuantum, TensorFlow Quantum and Azure Quantum. Its purpose is not to merge them. It selects or audits a path, refuses invalid comparisons, and stops once the minimum scientific evidence has been obtained.

Provisional preference: concepts 1 + 3 + 9. The preference remains reversible until the ten concepts have been scored and a golden-path probe succeeds.
