# Google Vids — 30-minute guided QCG tutorial

Status: `READY_FOR_LIVE_VOICE_SESSION`

This lesson uses the real WebMCP-QCG final demo. Codex operates Chrome while
Jean-Sébastien learns the controls and retains the only recorded narration
voice. No AI voice, avatar or synthetic demonstration is used.

## Teaching protocol for every control

Before each click, Codex will:

1. name the visible control;
2. explain what it does;
3. state what it will change in the current Vid;
4. connect that change to the QCG evidence story;
5. click once and let Jean-Sébastien observe the result;
6. undo or use a safe copy, then let Jean-Sébastien repeat each essential
   gesture once.

Codex remains silent while Jean-Sébastien records narration.

## Inputs ready before minute zero

- final QCG screen recording, separate from the provisional safety video;
- [QCG storyboard](VIDEO_SCRIPT_AND_STORYBOARD_2026-08-29.md);
- microphone selected, headphones connected and Windows notifications muted;
- `https://qcg.securedme.ca/` and the public repository URL ready for the final
  card;
- exact narrative limits: human decision, bounded local simulation, zero
  provider calls and zero QPU submissions.

## Minute-by-minute lesson

| Time | Guided action and learning result |
|---|---|
| 00:00–01:30 | Lock the contract: Vids edits a real recording; it does not manufacture evidence or replace the human voice. |
| 01:30–03:00 | Open `vids.new`, verify the Google account and microphone permission. Jean-Sébastien approves any account or microphone prompt. |
| 03:00–05:00 | Create a blank 16:9 Vid named `WebMCP-QCG — Final human-voice demo`. |
| 05:00–07:30 | Identify the canvas, scene list, playhead, timeline, object tracks and audio tracks. Compare editing Preview with clean Play. |
| 07:30–10:00 | Upload the final screen recording, fit it without stretching and mute unwanted source audio. Jean-Sébastien repeats clip selection and opens playback options. |
| 10:00–13:30 | Move the playhead, trim a clip and split a scene. Codex demonstrates, undoes, then Jean-Sébastien repeats the split. Only waiting time is removed; event order stays factual. |
| 13:30–16:00 | Align cuts with inspect, evaluate, human decision, local simulation, receipt, WebMCP, Access and the manual Gemini relay. Use direct cuts that preserve causality. |
| 16:00–18:30 | Add and duplicate short on-screen labels, attribution and the final live/repository URLs. Labels remain visible independently of captions. |
| 18:30–20:00 | Open `Record → Voiceover`, record a five-second microphone test, preview it and remove it. Explain level and noise controls before changing them. |
| 20:00–24:00 | Record Jean-Sébastien's real 2:50–2:55 narration. Codex stays silent. Preview, then insert; use section-sized takes only if one continuous take is uncomfortable. |
| 24:00–26:00 | Move and trim the narration track to synchronize actions. Jean-Sébastien repeats one safe track move. Split only to repair a local mistake. |
| 26:00–27:30 | Generate captions when available; correct `WebMCP`, `QCG`, `Q#`, `Codex`, `Gemini` and `Kulikowski`. |
| 27:30–29:00 | Run Preview for timing and Play for a clean review. Check privacy, chronology, human authority and zero-QPU proof. |
| 29:00–30:00 | Download/export MP4. Do not replace the YouTube video until the exported file passes the final checklist. |

## Export gate before YouTube

- measured duration below 03:00; target 02:50–02:55;
- a meaningful product action visible within 12 seconds;
- Jean-Sébastien's real voice only;
- human acceptance visibly performed by Jean-Sébastien;
- no reordered evidence, private notification, email address, local path,
  secret or credential;
- `external provider calls: 0` and `QPU submissions: 0` readable;
- Gemini output presented as imported, untrusted material;
- captions corrected and audio understandable on speakers and headphones;
- exact live and repository URLs visible;
- MP4 reviewed locally before YouTube upload.

## Interface fallbacks

- If `Upload` is absent, create the blank Vid first and import from Media or
  Insert.
- If `Voiceover` is unavailable, record Jean-Sébastien locally and import the
  resulting WAV or MP3; do not substitute an AI voice.
- If transcript correction is unavailable, trim or split audio at the playhead.
- If automatic captions are unavailable, add a manual caption track or import
  a UTF-8 SRT.
- If a control moved or changed name, Codex stops, explains the visible
  equivalent and its effect, then clicks; there is no blind trial-and-error.
- If export continues after minute 30, the lesson ends and processing may
  continue. Publication waits for the export gate.
