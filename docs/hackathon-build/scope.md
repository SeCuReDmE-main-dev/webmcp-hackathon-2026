# Build scope — WebMCP-QCG Day 3–Day 4 slice

## Outcome

Deliver one inspectable browser gate whose native agent path is:

`inspect → evaluate → conditional local simulation → export evidence`

## Included

- Four progressive WebMCP tools
- Five falsifiable decision cards
- Strict bounded contracts
- One Q# Bell-pair fixture in a Web Worker
- Visible one-time human consent
- Invocation provenance and zero-external-call counters
- JSON and Markdown evidence receipts
- Human interface that remains usable when WebMCP is absent
- Automated tests, production build and browser evidence

## Excluded

- QPU or provider submission
- Paid API calls
- Authentication to quantum providers
- General multi-provider conformance
- Arbitrary user-supplied quantum code
- Scientific interpretation or publication claims
- Final Devpost submission

## Acceptance

The slice passes when a WebMCP-capable browser discovers the progressive tools, invokes the complete bounded path, records 64 completed Bell shots with the invariant true, exports evidence and leaves the external-provider counter at zero.
